## 🛠️ Instructions
[cite_start][Explique aqui como compilar e executar o projeto[cite: 208].]
* **Compilation:** Run `make` to compile the `push_swap` executable.
* **Execution:** `./push_swap <list_of_integers>`
* **Flags:**
  * `--simple`: Forces O(n²) algorithm
  * `--medium`: Forces O(n√n) algorithm
  * `--complex`: Forces O(n log n) algorithm
  * `--adaptive`: Default behavior
  * `--bench`: Displays performance metrics on stderr
